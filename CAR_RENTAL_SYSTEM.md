# Car Rental System — গাড়ি লাগবে

## Overview

**Gari Lagbe** (গাড়ি লাগবে) is a car rental platform that connects vehicle owners with customers who need to rent cars.

## System Components

| Component  | Location    | Responsibility                        |
|------------|-------------|---------------------------------------|
| Frontend   | `frontend/` | User interface and client-side logic  |
| Backend    | `backend/`  | API, business logic, and data storage |
| Docs       | `docs/`     | Technical and user documentation      |

## Architecture

- **Frontend** and **Backend** are completely decoupled and communicate via REST API or WebSocket.
- Each service is independently deployable.

## Core Features (Planned)

- User registration & authentication
- Vehicle listing and search
- Booking and reservation management
- Payment integration
- Admin dashboard
